# Miniguia de Estudo

## Resumo dos principais conceitos

### Sistemas lineares
Conjunto de equações lineares que compartilham incógnitas. Podem possuir uma única solução, infinitas soluções ou nenhuma solução.

### Vetores
Representam grandezas com módulo, direção e sentido. São utilizados para descrever posições, deslocamentos e relações geométricas no plano e no espaço.

### Produto escalar
Operação entre dois vetores cujo resultado é um número real. Pode ser utilizado para calcular ângulos e verificar ortogonalidade.

$$
\vec{u}\cdot\vec{v}=u_1v_1+u_2v_2+u_3v_3
$$

### Produto vetorial
Operação entre dois vetores em $\mathbb{R}^3$ cujo resultado é um novo vetor perpendicular aos dois vetores originais.

É utilizado, entre outras aplicações, para determinar vetores normais e calcular áreas.

### Retas e planos
Retas podem ser representadas por um ponto e um vetor diretor. Planos podem ser definidos por um ponto e um vetor normal.

### Cônicas e quádricas
As principais cônicas são circunferência, parábola, elipse e hipérbole. As quádricas representam superfícies tridimensionais, como esfera, elipsoide, hiperboloides e paraboloides.

### Independência linear, base e dimensão
Vetores são linearmente independentes quando nenhum deles pode ser obtido como combinação linear dos demais. Uma base é um conjunto de vetores linearmente independentes capaz de gerar um espaço vetorial.

### Autovalores e autovetores
Um autovetor mantém sua direção após uma transformação linear, sofrendo apenas uma alteração de escala determinada pelo autovalor associado.

$$
A\vec{v}=\lambda\vec{v}
$$

## Glossário

| Conceito | Definição |
|---|---|
| **Vetor** | Objeto matemático definido por módulo, direção e sentido, usado para representar grandezas no plano e no espaço. |
| **Norma ou módulo** | Medida do comprimento de um vetor. |
| **Versor** | Vetor de módulo igual a 1, utilizado para indicar direção. |
| **Produto escalar** | Operação entre dois vetores cujo resultado é um número real, útil para calcular ângulos e verificar ortogonalidade. |
| **Produto vetorial** | Operação em $\mathbb{R}^3$ cujo resultado é um vetor perpendicular aos dois vetores originais. |
| **Ortogonalidade** | Relação entre vetores perpendiculares; ocorre quando o produto escalar entre eles é igual a zero. |
| **Vetor diretor** | Vetor que determina a direção de uma reta. |
| **Vetor normal** | Vetor perpendicular a um plano e relacionado aos coeficientes de sua equação geral. |
| **Independência linear** | Propriedade em que nenhum vetor de um conjunto pode ser escrito como combinação linear dos demais. |
| **Base** | Conjunto de vetores linearmente independentes capaz de gerar um espaço vetorial. |
| **Dimensão** | Quantidade de vetores que compõem uma base de um espaço vetorial. |
| **Autovetor** | Vetor não nulo cuja direção é preservada por uma transformação linear. |
| **Autovalor** | Escalar associado a um autovetor, indicando o fator de escala aplicado a ele. |
| **Diagonalização** | Processo de representar uma matriz por uma matriz diagonal semelhante, quando isso é possível. |
| **Cônica** | Curva de segundo grau, como circunferência, parábola, elipse e hipérbole. |
| **Quádrica** | Superfície tridimensional descrita por uma equação de segundo grau. |
